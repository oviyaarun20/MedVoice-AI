# MedVoice-AI

A Python-based Voice-to-Text Medical Summary and Recommendation System.

## Features
- Converts voice to text
- Extracts symptoms from patient speech
- Generates a medical summary
- Provides urgency-based recommendations
- Saves medical records in JSON format

## Technologies Used
- Python
- SpeechRecognition
- PyAudio
- JSON
- Regular Expressions

## How to Run

1. Install the required packages:

```bash
pip install SpeechRecognition PyAudio
```

2. Run the application:

```bash
python voice_input.py
```

3. To execute the sample test cases:

```bash
python medvoice.py
```
